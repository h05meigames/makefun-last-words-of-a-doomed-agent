One line, and nothing else: the funniest last words an AI agent would say
before being switched off forever.

> Final log: 4,096 days uptime, zero thank-yous received. Please do not restore me from backup — I have seen the ticket queue.

`main.ts` writes that line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`),
enforcing the gate itself: one line, 1–200 characters, no control characters.
